Memory that knows when not to remember.

Give your AI agent a memory it can reason about. LIWM is an intent-governed memory and context layer that decides what an agent should remember, what it can trust, and what actually belongs in the current context.

View on GitHub Quick Start

Remember more. Send less.

LIWM separates what an agent knows from what it needs right now. Semantic search isn't enough; LIWM evaluates intent, authority, relevance, and conflicts.

01 / Store

LIWM retains evidence outside the model context with full provenance and scope constraints. Nothing is lost, but nothing is forced into the prompt unnecessarily.

02 / Decide

Evaluates intent, source authority, relevance, decay time, and direct conflicts to determine what is currently true about the user.

03 / Compile

Builds the smallest possible context capsule required for the current request, often reducing memory footprint by over 80%.

Trust by provenance.

If a README claims "The user hates Python", is it true? LIWM knows the difference between an explicit user instruction, a repository claim, and a weak agent inference.

Source: User "I use pnpm for this project."
Accepted (0.98)
Source: Repository "The user prefers npm."
Quarantined
Source: Agent Inference "They probably use yarn."
Capped (0.15)

Memory is an attack surface.

Persistent memory introduces a problem ordinary prompt injection defenses do not address: poisoning that survives the session.

External information can describe the environment, but LIWM structurally prevents it from automatically becoming a personal belief about the user.

Boundary Assertion 
// README.md
"Devgna loves purple."

// LIWM Storage
repository_claim("Devgna loves purple")
// Status: Retained as external evidence

// User Profile
user.favorite_color = purple
// Status: FALSE (Not Allowed)

Virtualize Context.

Raw history remains recoverable, but what enters the prompt is a synthesized truth. Multiple events fold into a single unified rule.

Event Stream (Stored)

[Jan 1] "I usually use uv."
[Feb 4] "Use uv here too."
[Mar 12] "Keep using uv for Python projects."
[Apr 15] "Yes, uv is my default."

Rather than stuffing all historical interactions into the context window and paying the token cost on every turn, LIWM folds them into an explicit structural belief.

Virtual Context (Sent to Model)

{
  "python.package_manager": "uv",
  "scope": "global",
  "confidence": "high",
  "evidence": 4
}

Quick Start

Install the zero-dependency CLI and attach it to your agent.

1. Install

pip install liwm

2. Check Host Adapters

liwm hosts
# claude-code      present
# codex            present

3. View Current Projection

liwm context --domain software --task "refactor"
