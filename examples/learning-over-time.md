# Example: becoming quieter without guessing

This is a deterministic synthetic example, not a real person's profile.

## Interaction 1

The user says, “For implementation work, make the change and give me the short
version afterward.” LIWM records a direct, software-domain observation for high
autonomy and concise explanation. Each has strong but non-certain confidence;
it does not infer anything about writing, design, or the person's intelligence.

AUTO sees a novel, consequential authentication task with low specification
completeness. It resolves to MEDIUM and asks one direct constraint question
because it could change the architecture.

## Interaction 2

The agent asks three questions before a reversible refactor. The user says,
“You didn't need to ask those.” LIWM records explicit `too_many_questions`
feedback. The personal strategy's questioning thresholds move slightly upward,
bounded to a small step. The project outcome does not become a global trait.

## Interaction 3

For another software refactor, the domain evidence is mature and the operation
is reversible. AUTO now resolves LOW, states one assumption, implements, and
gives a short handoff. The user accepts the first pass. Question count falls
while acceptance improves.

## Interaction 4: exception, not contamination

The user says, “This banking migration must be extremely conservative; show the
plan before editing.” That becomes a project non-negotiable and overrides the
learned autonomy preference. LIWM does **not** change the global user model to
“always conservative.” A later visual-design task still has no evidence for
conservatism and starts with uncertainty.

## Interaction 5: correction

The profile hypothesizes that examples are preferred. The user says, “That
isn't true for mathematics; start from first principles.” LIWM rejects the weak
mathematics hypothesis, stores the rejection, and records the direct
domain-specific replacement. Repeated weak behavior cannot resurrect the old
claim; only a later direct statement can.

The measurable change is not “LIWM knows the person.” It is narrower: prediction
accuracy on supported software interaction dimensions rises, unnecessary
questioning falls, and project exceptions remain scoped.
